v78 逐题答案对应修复版

一、问题根因
v74-v76 将完整题组由“整页资料”拆成逐题纯文字卡片时，生成了新的题目 ID。
原来的答案文件仍挂在旧的整页记录或整套题组上，没有按照新题目 ID 重新绑定。
因此页面虽然显示了逐题题干，但“查看答案”读到的是空答案或“请按原题号查阅”的整套占位说明。
这不是用户没有提供答案，而是此前数据重构后没有执行答案重匹配。

二、本版已修复
严格按“题源 + 完整题组 + 题型 + 原题号”重新绑定当前安装包中能够明确确认的正式答案资料：
1. 蓝色森林《第二节 极限》：94题全部对应。
2. 蓝色森林《第四节 形容词与副词》：35题全部对应。
3. 全方位《第1章 计算机概述》：47题全部对应。
4. 蓝色森林《第三节 连续与间断》：保留此前已对应的39题。

本次新增逐题绑定共176题；加上连续与间断39题，上述4套共215题均已有对应答案。
选择题直接显示答案字母；英语翻译题显示参考答案；数学复杂公式题同时绑定到对应的官方答案解析图片，避免公式再次被错误转写。

三、修复的缓存问题
app.js 的题库内容修订号已升级为 v78。首次打开会重新写入答案字段，但不会清除已完成、错题、做对/做错次数和学习时长。

四、校对说明
全方位计算机概述第18题：当前纯文字题干有两个空，但用户提供的正式答案资料只给出“运算速度快”一项。本版标记为“资料冲突”，不擅自补第二项。

五、未强行处理
其余暑假题组当前安装包中没有能够通过“题源 + 题号 + 题干”确认的一对一正式答案映射。本版已清除错误的整套占位答案，但没有使用常识或自动生成答案冒充用户答案。详细情况见 audit-report-v78.json。
