v73 完整题组统一逐题对应修复说明

本次版本在 v67 题库基线的后续修复基础上，继续处理了“完整题组”展示问题。

本次已完成：
1. 所有完整题组不再使用“整页占位卡片”作为纯文字版主展示。
2. 所有完整题组统一改成“逐题对应”的题号卡片模式。
3. 其中：
   - 第三节《连续与间断》已按逐题内容修复为 39 题。
   - 其余完整题组统一改成“题号一一对应 + 原图辅助”的保守修复方式，避免再次出现大段乱码。
4. 所有完整题组仍保留原图、来源、答案PDF/答案图（如原数据已有）等信息。
5. completeSetRegistry 中已不再保留 pageMode=true 的完整题组。

说明：
- 这次重点是先把“完整题组”的结构全部改对，让纯文字版浏览逻辑统一。
- 对于原始清晰度不足、容易 OCR 乱码的整页资料，本版优先保证“题号对应正确”和“原图可辅助作答”，不强行生成不可靠乱码文字。
